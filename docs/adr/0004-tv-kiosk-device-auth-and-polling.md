# Autenticação por Token de Dispositivo e Polling Resiliente para TV Kiosk

Adotamos para o módulo de exibição passiva em Smart TVs (`/tv`) um modelo de autenticação baseado em Token de Dispositivo (UUID v4 persistido em `localStorage`) pareado via código numérico temporário de 6 dígitos, com sincronização de agendamentos via polling HTTP a cada 20 segundos em API Route segura (`/api/tv/appointments`). Excluímos a rota `/tv` do middleware de autenticação Supabase Auth e evitamos WebSockets diretos do Supabase Realtime no client da TV porque navegadores embarcados de Smart TVs (Tizen, webOS) e dongles não possuem usuário logado, perdem conexões WebSocket persistentes silenciosamente e possuem restrições severas de hardware. A API Route utiliza `supabaseAdmin` no servidor para validar o token e aplicar rigorosa anonimização LGPD antes de transmitir os dados para a tela pública.
